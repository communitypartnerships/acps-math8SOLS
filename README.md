This data was drawn from the [VDOE Build-a-Table site for Standardized Test Data](https://p1pe.doe.virginia.gov/apex_captcha/home.do?apexTypeId=306) to understand the Math enrollment and achievement of 8th graders in Albemarle County Public Schools over time and by membership groups of interest. This project was co-developed with Albemarle County Public Schools via a Research-Practice Partnership between ACPS and CCP. Data was wrangled and used via Tableau to create [a series of dashboards] on how students enroll and achieve in Math 8, Algebra 1, and Geometry in the 8th grade across membership groups. 

Contained in this repository are data, scripts, and documentation on the wrangling of VDOE Build-a-Table data into Tableau-compatible structures for publicly available standardized test data in Albemarle County Public Schools. We hope that the documents in this repository will provide a pathway for data integration and wrangling for anyone interested in using Build-a-Table public data to better understand student achievement outcomes in Virginia. 


### How to use this repository

In "documentation", a Data Guide exists for how data was downloaded from the VDOE Build-a-Table to be brought into R and structured for use in Tableau.
In "scripts", an R script exists that wrangles multiple datasets from the VDOE Build-a-Table into an integrated data structure for Tableau.
In "data", data downloaded from Build-a-Table, as well as cleaned data for this project is made available.
